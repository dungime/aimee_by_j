# Reference only — not part of the workspace

This is the original, unmodified [Medusa DTC Starter](https://github.com/medusajs/dtc-starter)
storefront (Next.js), kept as a reference while `apps/storefront` is rebuilt from
scratch.

- **Not** in `pnpm-workspace.yaml` — no install, build, dev, or deploy runs here.
- **Not** developed further — treat it as read-only source to consult (cart/checkout
  flow, Medusa API integration patterns, component structure), not to copy wholesale.
- The live project is [`apps/storefront`](../storefront).

If you want to actually run this app standalone to compare behavior, `cd` into it
and `npm install` independently — it won't affect the pnpm workspace.
